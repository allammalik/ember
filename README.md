# EMBER — Cold-Smoked Herbal Aperitivo

A scroll-driven product landing page for **Ember**, a fictional cold-smoked herbal aperitivo by Lodestar. Built by [makewebb](https://makewebb.vercel.app).

## Features

- Scroll-rolling 3D bottle (Three.js r152, LatheGeometry glass + canvas-drawn label)
- Floating ember particles with parallax
- Working bag / checkout drawer and newsletter signup validation
- Pure static HTML/CSS/JS — no build step

## Run locally

```bash
python -m http.server 8765
# open http://localhost:8765
```
